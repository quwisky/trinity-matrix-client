Code size

Sizes code in messages — both code written inside a sentence and whole blocks. It is relative to Text size, so the two work together rather than one overriding the other.

Line numbers

Numbers the lines of a code block, so you can point at one. They are never part of the message: selecting or copying a block gives you the code alone.
