# Documentation ownership

Use this inventory when changing a guide, moving a topic, or checking whether a source-owned
reference belongs in the documentation tree. [The documentation index](index.md) is the reader
entry point; this page records ownership and the dispositions from the
[documentation rewrite](https://github.com/quwisky/trinity-matrix-client/issues/543).

## Maintain one canonical guide per task

- Route user tasks through [Using Trinity](users/index.md), development through
  [Contributing](contributing/index.md), operational work through [Maintaining](maintaining/index.md),
  and agent use through [Working with agents](agents/index.md).
- Keep architecture, platform, stack, and troubleshooting detail behind relevant task links.
  A source-adjacent README explains that local tool or suite and links the shared contract.
- Coordinate shared files through one writer. Update incoming links and anchors with a move;
  avoid keeping multiple substantive copies of commands, policy, or architecture claims.
- Record the revision and actual validation with a change. Current guides describe implemented
  behavior; ADRs and dated results preserve their historical context.
- Maintain generated and imported content through its owning tool. First-party catalogs and
  overrides provide repository behavior without rewriting upstream files.

## Reconciled baseline

The authoritative code baseline is `refactor/refine-architecture` at
`dbd200ce3b6c289d9dea291d52947658dedc621c`, including merged PR #532.
Its **260 Markdown paths** comprise the **78 individually listed paths** below,
**164 files in 22 managed skill folders**, and **18 Spartan READMEs**.
Five first-party guides were added and three superseded files removed, leaving
**262 Markdown paths** in this rewrite's reconciled checkout. These are audit snapshot
counts, not numbers to update for every future documentation edit.

Every baseline path has a current destination or justified disposition. Existing agent
router pages remain conditional pointers; the two temporary contributor compatibility
pages were removed after their incoming links moved. The superseded UI plan's active
requirements remain in [truthful loading](https://github.com/quwisky/trinity-matrix-client/issues/545)
and [Settings search](https://github.com/quwisky/trinity-matrix-client/issues/546), with
[the remaining direction decision](https://github.com/quwisky/trinity-matrix-client/issues/547)
kept separate from implemented behavior. These product follow-ups do not expand this rewrite.
